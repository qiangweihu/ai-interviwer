# AI 模拟面试官

面向准备大厂实习面试或保研复试的本科生，提供可反复练习、有针对性反馈的 AI 模拟面试体验。

> 项目正在 16 小时挑战中快速迭代。目标用户、核心场景和 MVP 边界将在用户调研后进一步收敛。

## 核心问题

- 学生难以找到资深学长或专业人士进行高频对练。
- 普通练习缺少针对具体表现、可立即执行的反馈。
- 产品需要形成“面试 - 反馈 - 再练习”的完整训练闭环，而不是简单复刻通用聊天工具。
