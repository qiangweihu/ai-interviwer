## 主题与问题主线

1. **开场与动机（2 分钟，oral）**：请用两分钟介绍自己，以及为什么想做视觉表征学习。
2. **计算机视觉基础（3 分钟，oral）**：卷积网络中的感受野和下采样分别带来什么影响？
3. **项目事实核验（4 分钟，oral）**：在室内机器人项目中，你个人负责的训练和误差分析具体怎么做？
4. **实验设计（4 分钟，oral）**：`71.2% → 74.8%` 的提升如何证明来自数据增强而非随机波动？
5. **跨模态检索（3 分钟，oral）**：CLIP 的图文对比目标如何帮助以文搜图？
6. **失败复盘（3 分钟，oral）**：项目中哪个假设没有成立，你如何定位原因？
7. **算法实现实操（10 分钟，coding / Python 或 C++）**：读取整数序列并输出总和；约束为第一行给出 n（可为 0）、第二行给出 n 个整数；先试跑公开样例，最终提交后运行隐藏边界测试。
8. **代码理解与调试（8 分钟，code_review）**：解释按标准输入读取的平均值程序在空输入和单元素输入上的问题，并提交可选 stdin/stdout 修正版。

每题根据回答保留 1–3 个动态追问；实操题只展示公开材料，隐藏测试、参考解法和 rubric 不展示。重点观察基础概念、个人贡献、实验因果、研究问题意识、代码边界处理和表达结构。

Mock MiMo 还内置完全虚构的替代实操材料：请求“数据库/SQLite”方向时使用只读 SQL 统计题，请求“实验结果分析/日志分析”方向时使用指标与日志判断题；两者都可与 C++20 标准输入输出题组合验收。
